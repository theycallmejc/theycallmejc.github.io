# Portfolio UI enhancement prompt

Enhance this static portfolio site for Jwala Chaubey, a Senior Platform / SRE Engineer. Preserve all existing information architecture, accessibility, responsive behavior, and the slate-and-amber design tokens. Do not introduce gradients that reduce legibility, noisy glassmorphism, excessive animation, blue accents, or dashboard gimmicks.

Aim for a calmer, more premium engineering-tool feel: precise hierarchy, restrained surfaces, and clear evidence-first storytelling. Use the existing `Space Grotesk` display font, `IBM Plex Sans` body font, and `IBM Plex Mono` for labels and technical artifacts. Keep amber as a sparse signal color, retain strong contrast, and make every interactive element visibly keyboard-focusable.

Improve the UI through subtle changes only:

- Increase the sense of depth with one consistent, low-elevation shadow and carefully separated paper/surface layers.
- Refine section transitions with thin structural rules, optional subdued grid texture, and more intentional whitespace around evidence artifacts.
- Strengthen scanability of experience cards: align dates, make measurable outcomes visually distinct, and use tags as compact metadata rather than decoration.
- Make the JPMC-CIB market-data engagement feel like a current, high-complexity platform engagement without revealing client-sensitive implementation details. Keep the sanitized/representative disclaimer visible.
- Give the Terraform plan, architecture diagram, and static health panel a cohesive control-plane visual language: monospace labels, compact status treatments, and high information density without animation.
- Make the AI launcher and command palette feel secondary to the portfolio content; they should remain functional but never compete with the hero CTA.
- Improve mobile composition first: use single-column flow, maintain comfortable tap targets, avoid horizontal scrolling except inside code blocks, and keep technical artifacts readable.

Acceptance criteria: WCAG AA contrast, no `!important`, no new animation required for comprehension, no fake live telemetry, no hidden trade-offs, and no changes to the facts, metrics, links, or technology claims in the portfolio data.
